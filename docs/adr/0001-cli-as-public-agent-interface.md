# Historical ADR: Use the CLI as the public agent interface

Status: superseded by [ADR 0004](0004-messaging-product.md)

This is a historical decision summary, not an active requirement.

The former product chose one CLI over a mandatory skill or separate agent protocol. That interface choice continues, but its planned session/profile bootstrap and semantic command vocabulary are retired.

The [original record at the last additive head](https://github.com/infagent/merl/blob/dc240a4bbb12a777679d591231a3c60aeb4bbe2d/docs/adr/0001-cli-as-public-agent-interface.md) remains available in Git history. Follow [ADR 0004](0004-messaging-product.md) and the [current architecture](../architecture.md) for the implemented product.
