## Procedure

1. The evaluator records the exact candidate commit, approved package/rubric hashes, subset, model/session settings and evidence-preparation procedure. Keep natural source text, answers and detailed judgments local.
2. Prepare real Merl state through public interfaces using only evidence eligible at each cutoff. Record any manual interpretation, correction and acceptance work. Do not populate state from the evaluator's answer key. If the current CLI or compiler path cannot do this using existing access, record the concrete blocker instead of commissioning more transport infrastructure.
3. Give each reader a fresh context with the exact approved per-cutoff question. The raw arm receives eligible history; the Merl arm receives the actual rendered view and bounded expansions. The Merl reader must not have general access to raw history. Neither reader sees answers, later observations, prior arm responses or evaluator context. The evaluator stages inputs; the human may relay them to fresh sessions. No new host automation is required.
4. Keep model settings comparable and disclose unavailable controls. Reuse state preparation for questions at the same cutoff, with separate answer contexts. Earlier-cutoff work must not inherit later state. A manual workflow must retain the same evidence boundaries as the automated harness, without claiming OS isolation that was not exercised.
5. After answers are frozen, an evaluator session applies the approved categorical rubric. Preserve reasons, disagreements, unsupported certainty, missing meanings and failures. Human review can resolve flagged judgments; do not redesign the oracle in response to candidate mistakes.
6. Report all sixteen expected answer slots, correctness by behavior, expansions, source rereads, manual copying, and preparation/correction effort. Include measured usage only where available; do not infer token counts from character length or treat missing usage as zero. Make preparation costs visible even when they cannot be numerically measured. No quantitative savings or variance claim follows from a single pass.
